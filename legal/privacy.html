2. いま、私たちが集めていないもの

先に、集めていないものを書きます。ここが本作の実情です。

  • アカウントを作りません。 メールアドレスもパスワードも要りません
  • サーバーにあなたのデータを保存していません。 保存先はあなたの端末（ブラウザ）だけです
  • 広告を配信していません。広告用の識別子も、第三者の広告タグも入っていません
  • SNS のトラッキング用タグ（「いいね」ボタン等）を1つも置いていません
  • あなたの発話・会話・プレイ内容を、当方が読める場所へ送っていません

これは方針ではなく、現在公開しているビルドの事実です。
公開している JavaScript を検査したところ、ゲームの動作のために接続する
外部サーバーは含まれていませんでした（画像・音声・スクリプトはすべて
このサイト自身から読み込まれます）。

3. あなたの端末に保存されるもの

本作は、あなたのブラウザの localStorage にセーブデータを置きます。
サーバーには送られません。同じブラウザの中にだけあります。

キー中身
amour-eternel:save:v1主人公の名前、各キャラクターへの好感度、関係性、読了したエピソード、解放したCG・記憶、ゲーム内通貨と購入履歴、物語の見え方の設定、灯火（AI会話）の残量・履歴・記憶・ミッション進捗
amour-eternel:metrics:v1アクセス解析を有効にしている場合のみ。送信済みかどうかの真偽値だけ（§6）
amour-eternel:no-analyticsアクセス解析の停止設定（§6）
amour-eternel:legal-bar-hidden画面隅の注意書きを閉じたかどうか

主人公の名前に本名を入れる必要はありません。呼びかけに使う表示名です。

消し方

  • ブラウザの設定から、このサイトの「サイトデータ」を削除してください。すべて消えます
  • 灯火の記憶だけを消したい場合は、ゲーム内の記憶画面から1件ずつ、または全件消せます（§4）

セーブはあなたの端末にしかないので、削除すると復旧できません。
別の端末やブラウザに引き継ぐ手段も、現時点ではありません。

4. 灯火（AI会話）で、あなたの言葉がどこへ行くか

「灯火（ともしび）」は、キャラクターと自由に会話できる機能です。
ここが本作でいちばん説明が要る部分なので、細かく書きます。

4-1. いま公開している Web 版では、外部に送られません

灯火には応答の作り方が2通りあります。

経路何が起きるかいまの状態
端末内（local）応答をあなたの端末の中で組み立てます。通信は発生しませんこれで動いています
サーバー経由（server）当方のサーバーへ送り、そこから対話AI（大規模言語モデル）へ問い合わせます無効。接続先が設定されていません

公開しているビルドにはサーバーの接続先が設定されていません。
そのため、あなたが灯火に打ち込んだ文章は、あなたの端末から出ません。

4-2. サーバー経由を有効にしたら、何が送られるか

将来サーバー経由に切り替えるときに送る項目は、すでに決まっています。
下のものだけを送ります。これ以外は送りません。

送るもの内容
キャラクターID誰と話しているか（例: leon）
あなたの発話そのとき打ち込んだ本文
表示名呼びかけに使う名前（本名である必要はありません）
好感度0〜100 の数値。返事の距離感に使います
要約された記憶呼び名、覚えている事柄、話題の語、会話の往復数（§4-3）
直近のやり取り直近10件まで。会話の全文履歴は送りません
灯火の状態彼から始まった会話か、残り往復数、残量

送らないもの: 過去の会話の全文、他のキャラクターとの会話、
セーブデータ全体、端末やブラウザの識別子、位置情報、連絡先。

対話AIの API キーはサーバーにしか置きません。
アプリ側に鍵を埋め込むと必ず抜かれるため、構造として禁じています。

4-3. 何を「覚える」のか、どう消すのか

灯火は会話を要約して覚えます。全文は溜めません。

種別例上限
プロフィール呼ばれ方の好み、好きなもの8件
出来事「試験が近いと言っていた」10件
話題よく話す言葉12件
関係の履歴初めて名前を呼んだ日6件
  • 記憶はキャラクターごとに独立しています。レオンに話したことをハルは知りません
  • 上限を超えると、古い・弱いものから落ちます
  • 抽出は単純な言葉の拾い上げで行うため、見当違いのことを覚える場合があります。

だからこそ、**ゲーム内の記憶画面で、何を覚えられているかを全部見られて、
1件ずつ消せます。全件まとめて消すこともできます**

  • 記憶で変わるのは話題の選び方・呼び方・距離感だけです。

性格・一人称・禁則は記憶では変わりません

4-4. 無料枠の対話AIについて（ここは正直に書きます）

対話AIの提供元は、**無料の利用枠では、入力と出力を自社サービスの改善に利用し、
人間がその内容をレビューする場合がある**としています。

灯火にこれを使うことは論外だと考えています。
したがって、**灯火のサーバー経由の応答は、学習に利用されない有料の利用枠に
切り替えるまで有効にしません。**現在は §4-1 のとおり無効です。

有効にするときは、**この文書を先に更新し、どの事業者のどのサービスへ、
どの条件で送るのかを明記します。**

4-5. 灯火は人間ではありません

  • 相手はAIです。訊かれれば彼ら自身もそう答えます
  • 生死・医療・法律・自傷など深刻な話題では、キャラクターを保ったまま

現実の相談窓口を案内する応答に切り替わります。
緊急のときは、AIではなく現実の窓口に連絡してください

  • 応答は生成後にも検査され、キャラクターの禁則に触れたものは表に出ません

公式サイトには事前登録フォームがあります。

送信先が設定されていないため、フォームは送信自体をブロックしています。
つまり、現時点で当方はメールアドレスを1件も受け取っていません。
「送ったのに届いていない」状態を作らないための処置です。

5-2. 受付を開始したときの扱い

受付を始めるときは、**開始前にこの文書を更新し、保管先（利用する配信サービス名）を
明記します。**そのうえで、次を守ります。

項目内容
集めるものメールアドレスと、お知らせを受け取ることへの同意
使う目的配信開始のお知らせと、事前登録特典の案内のみ
しないこと第三者への提供・販売、広告配信への利用、他社データとの突合
解除配信メール内のリンク、または §10 の窓口への連絡でいつでも
削除解除の時点で削除します。配信開始から6か月を過ぎたものも削除します

6. アクセス解析

6-1. なぜ数えるのか

本作の事業計画は「何人が来て、何人が第1話を読み終えるか」の仮定の上に立っています。
これを実際の数字に置き換えないと、どこを直せばよいのか分かりません。
ただし、個人を追いかける必要はありません。匿名の合計だけで足ります。

6-2. いまの状態

アクセス解析は無効です。送信先が設定されておらず、
計測のための通信は1件も発生していません。

6-3. 有効にしたときに送るもの（これで全部です）

有効にした場合でも、送るのは次の5種類の固定の文字列と、
キャッシュ回避用の乱数だけです。1×1の画像を取得する形で送られます。

送る文字列意味
/lp公式サイトのページが表示された
/playゲームのページが表示された
start主人公の名前を決めた（＝実際に遊び始めた）
ep1-clear第1話を読み終えた
ep2-clear2話目まで読み終えた

start ep1-clear ep2-clear は、1つのブラウザにつき1回だけ送られます。

送らないもの: Cookie、ユーザーID・端末IDのような識別子、
どこから来たか（リファラ）、画面サイズ、URLのクエリ文字列、ページタイトル、
主人公の名前、会話の内容、セーブデータ。

判定は、あなたの端末にあるセーブデータを読むだけで行います。
セーブデータ自体はどこにも送られません。

なお、インターネットの仕組み上、**送信先のサーバーには
あなたのIPアドレスとブラウザの種類（User-Agent）が渡ります。**
これはあらゆる通信で避けられないことなので、隠さずに書いておきます。
利用を予定している解析サービス（GoatCounter）は、Cookie を使わず、
個人を識別する保存を行わないと説明していますが、**当方はその内部処理を
検証できていません。**サービス名は、有効化と同時にこの欄へ明記します。

6-4. 止め方

  • プライバシーポリシーのページ末尾に停止ボタンがあります。押せば、そのブラウザでは以後送信しません
  • ブラウザの Do Not Track を有効にしている場合は、押さなくても停止しています
  • ブラウザのサイトデータを消せば、計測用の印（amour-eternel:metrics:v1）も消えます

7. ホスティングについて（GitHub Pages）

本作の Web 版と公式サイトは GitHub Pages（GitHub 社）で配信しています。
ページや画像・音声を読み込むと、**GitHub のサーバーにあなたのIPアドレスと
ブラウザの種類が渡ります。**これは当方が制御できない、Webの仕組み上の通信です。

9. 未成年の方へ

  • 本作は無料で、課金は実装されていません
  • 18歳未満の方は、保護者の同意を得たうえでご利用ください
  • 課金を導入するときは、年齢の申告と、未成年の上限額の仕組みを先に用意します
  • 保護者の方から、お子さまに関する情報の削除を求められた場合は §10 へご連絡ください。

ただし §3 のとおり、データはお子さまの端末の中にしかありません。
ブラウザのサイトデータを削除すれば、それで全部消えます

10. お問い合わせ・開示や削除の求め

この文書の公開時点で、公開の問い合わせ窓口（メールアドレス）をまだ用意できていません。
ごまかさずに書きます。

現時点で当方が保有しているあなたの個人データは存在しません（§2・§3）。
そのため、開示・訂正・削除の求め先が実際に必要になるのは、
事前登録の受付を開始する時点です。

受付開始より前に、この欄に連絡先を記載します。
それまでの間、データの削除はブラウザのサイトデータ削除で完結します（§3）。
